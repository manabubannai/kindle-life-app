# Kindle Life

**メルマガとブログを、届いた順に1件ずつKindleへ。**

Gmailに届くメルマガと、お気に入りブログの新着記事を、届いてから1時間以内に、1件ずつそのままあなたのKindleに自動送信します。Kindleライブラリでは、メルマガの件名・記事タイトルがそのまま書名になります。

- 🆓 **完全無料** — サーバー不要。すべてあなたのGoogleアカウントの中で動きます
- 🔒 **プライバシー** — メールも設定も、開発者のサーバーには一切送られません
- 🧑‍💻 **プログラミング不要** — スプレッドシートをコピーして、表に書き込むだけ

## 使い方（3ステップ・約10分）

1. **テンプレートをコピー** → [コピーリンク（準備中）](#)
2. シートは1ページだけ。**赤い枠の3箇所**に書き込む（①自分のSend to Kindleアドレス ②メルマガの差出人アドレス ③ブログのURL※トップページでOK）
3. メニュー **「Kindle Life」→「① 初期セットアップ」** を実行してGoogleの許可画面でOK

以後は新着が届くたびに（最長1時間ほどで）、1件ずつKindleに届きます。

毎日届くメルマガなど、1通ずつだと多すぎる場合は、差出人アドレスの右のセルに好きなタイトル（例:「◯◯メルマガ」）を書くと、その差出人だけ**毎週月曜の朝に1冊にまとめて**届きます（書名は「◯◯メルマガ 7/27〜8/2」のようになります）。

仕上げに、Amazonの「[コンテンツと端末の管理](https://www.amazon.co.jp/hz/mycd/myx)」→「設定」→「承認済みEメールアドレス」に自分のGmailアドレスを追加し、「🧪 テスト送信」で確認してください。

詳しくは [セットアップガイド](docs/setup-guide-ja.md) を参照。

> 🤖 **Claude Code等のAIエージェントを使える方へ**: シートのコピーすら不要です。[エージェント向けセットアップ・プロンプト](docs/agent-setup-prompt.md)をあなたのエージェントに貼れば、セットアップを丸ごと任せられます。

## 仕組み

```
あなたのGmail（メルマガ）─┐
                          ├─ 毎時、あなたのGoogleアカウント内のスクリプトが
ブログのRSS/Atomフィード ─┘   新着を確認し、1件ずつ自己完結HTMLに変換
                                 │
                                 └→ あなたのGmailから ○○○@kindle.com へ1件1通で送信
                                     （Send to Kindle公式のメール方式）
```

- ブログはトップページのURLを貼るだけ（RSS/Atomフィードの場所は自動検出）
- 抜粋だけのフィードでも、記事ページから全文を取得します
- 画像は埋め込み済み（Kindleはリモート画像を取得しないため）
- Substack等の複雑なメールHTMLも、本文が欠けないようクリーンアップします

## 開発者向け

構成: Googleスプレッドシート（設定UI）+ コンテナバインドGAS。外部ライブラリ・ビルドなし。

```
src/            # GAS本体（claspでpush）
├── main.gs     # エントリポイント（毎時トリガー・個別配信）
├── config.gs   # named range経由の設定読み書き
├── gmail.gs    # メルマガ収集（gmail.readonly）
├── rss.gs      # RSS 2.0 + Atom巡回・全文取得
├── html.gs     # 白リストクリーナー・画像埋め込み（共通エンジン）
├── digest.gs   # 1冊ぶんのHTML組立（個別＋週1まとめ）
├── mail.gs     # Kindle宛送信・エラー通知
├── state.gs    # 処理済みID/GUID（ScriptProperties）
├── triggers.gs # トリガー管理
├── ui.gs       # メニュー・セットアップ・診断
├── update.gs   # 新バージョン通知
└── dev.gs      # テンプレシート構築（開発者用）
```

テンプレートの作り方・配布手順は [docs/template-checklist.md](docs/template-checklist.md) を参照。設計の全体像は [SPEC.md](SPEC.md) / [DESIGN.md](DESIGN.md)。
