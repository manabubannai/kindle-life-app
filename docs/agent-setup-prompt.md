# エージェント向けセットアップ・プロンプト（コピペ配布用）

Kindle Lifeの「もう一つの配布形態」。スプレッドシートのコピーリンクの代わりに、
**下のプロンプトを丸ごとコピーして、自分のClaude Code（または同等のコーディングエージェント）に貼るだけ**でセットアップが完了する。

- 対象: Claude Code等のAIエージェントを使える読者（シートコピー方式は非エンジニア向けとして併存）
- 前提: このリポジトリが https://github.com/manabubannai/kindle-life-app で**公開されていること**
- 仕組み: エージェントが clasp でシート+バインドスクリプトを新規作成し、`DEV_buildTemplate()` で設定UIを組み上げるため、**テンプレートシートの配布が不要**になる

---

## 配布用プロンプト（ここから下をコピー）

```text
あなたに「Kindle Life」のセットアップを任せます。

Kindle Lifeは、Gmailに届くメルマガとお気に入りブログの新着を、届いた順に
1件ずつ自分のKindleへ自動送信する無料ツールです（1件 = Kindleの1冊）。
サーバー不要で、すべて私自身のGoogleアカウントの中だけで動きます。

コード: https://github.com/manabubannai/kindle-life-app （MITライセンス）

以下の方針で、私と対話しながらセットアップを完了してください。

1. リポジトリをcloneし、README.md → docs/template-checklist.md の順に読んで
   全体像を把握する（仕様の詳細は SPEC.md / DESIGN.md）。
2. Google公式CLI「clasp」を使って、私のGoogleアカウントに
   新しいスプレッドシート＋コンテナバインドのApps Scriptプロジェクトを作る。
   - claspが無ければインストールし、`clasp login` は私にブラウザで実行させる
   - Apps Script APIの有効化（script.google.com/home/usersettings）が必要なら案内する
   - src/ の全ファイルと appsscript.json をそのまま push する（コードは改変しない）
3. スクリプトエディタで関数 `DEV_buildTemplate` を1回実行するよう私を案内する。
   これで設定シートのUI（赤枠の入力エリア3つ）が自動で組み上がる。
   初回実行時のGoogleの許可画面（「詳細」→「移動」→「許可」）も先回りして説明する。
4. シートの赤枠3箇所の埋め方を私に確認しながら進める:
   ① 私のSend to Kindleアドレス（○○○@kindle.com。Amazonの
      「コンテンツと端末の管理」→「設定」→「パーソナル・ドキュメント設定」で確認）
   ② 受け取りたいメルマガの差出人アドレス（1行に1つ）
   ③ 読みたいブログのURL（トップページでOK。フィードは自動検出される）
5. シートのメニュー「Kindle Life」→「① 初期セットアップ」を私に実行させる。
6. Amazonの「コンテンツと端末の管理」→「設定」→「承認済みEメールアドレス」に
   私のGmailアドレスを追加するよう案内する（これをしないとKindleに届かない）。
7. メニューの「🧪 テスト送信」でKindleに届くことを確認したら完了。
   以後は新着が届くたび（最長1時間ほどで）1件ずつ自動で届くことを説明する。

守ってほしいこと:
- 私のKindleアドレス・メルマガ・ブログの情報を、私のGoogleアカウントと
  このマシンの外に送らない（このツールの設計思想でもある）
- つまずいたらメニューの「🩺 診断」と docs/ を手がかりに自力で解決を試みる
- 不明点は勝手に進めず私に質問する
```

## 配布時のメモ（マナブ向け）

- **公開が唯一のブロッカー**: リポジトリはpush済みだが現在**プライベート**（外部からは404）。リリース残タスクの「GitHub公開」が完了した瞬間からこのプロンプトは動く
- プロンプト内のURLが読者のチャット→エージェント→GitHubへ流れる = 配布そのものがリポジトリへの導線になる
- claspのサブコマンドはバージョンで変わるため（`create` / `create-script`）、プロンプトでは意図だけ伝えてエージェントに解決させる書き方にしてある
- 人間にしかできない操作は3つだけ: Googleログイン許可 / 初回実行の許可画面 / Amazonの承認済みアドレス追加
